# Планировщик ухода за растениями

**Автор:** Мухаметов С.М.
**Группа:** ТОП-ИТ-101Б

## Описание проекта

Простое MVP веб-приложения для создания заметок и планирования ухода за комнатными растениями. Приложение позволяет пользователям добавлять растения, вести журнал
наблюдений, устанавливать напоминания о поливе и других процедурах, а также отслеживать состояние добавленных растений.

## Структура проекта

project/<br>
├── public/ # Статические файлы для фронта<br>
├── src/ # Исходный код<br>
│ ├── algorithm/ # Алгоритмы обработки данных<br>
│ ├── core/ # Основная логика приложения<br>
│ ├── structures/ # Структуры данных<br>
│ └── server.js # Точка входа сервера<br>
├── test/ # Тесты<br>
├── demo.js # Демонстрационный скрипт<br>

## Ключевые компоненты

- **server.js** — обработка запросов, логика работы с заметками и напоминаниями.
- **папка public** — статические HTML, CSS файлы для интерфейса пользователя.
- **папка src, всё кроме server.js** — модули для обработки данных о растениях.

## Технологии

- **Backend:** Node.js
- **Frontend:** HTML, CSS, JavaScript
- **Сервер:** Express JS
- **Управление зависимостями:** npm

## Установка и запуск

1.  Клонируйте репозиторий:<br>

    ```bash
    git clone https://github.com/Shade-Angel/project.git
    cd project
    ```

2.  Установите зависимости<br>

    ```bash
    npm install
    ```

3.  Запустите сервер<br>

    ```bash
    node src/server.js
    ```

    Или <br>

    ```bash
    npm start
    ```

4.  Откроестся браузер, если не открылся надо открыть браузер вручную и перейти по адресу( в большинстве случаев http://localhost:3000).

5.  Также можете запускать тесты и демо вариант (нужен отделный терминал)

- Тесты<br>
  `node test/test.js`

- Демо<br>
  `node demo.js`

6. Можно также упокавать приложение в .exe файл

```bash
npm run build:exe
```

7. Можно делать автоисправления с помощью линтера ESLint

- Проверка проекта<br>
  `npm run lint`

- Автоисправление<br>
  `npm run lint:fix`

## Скачать

Чтобы скачать приложение нужно найти Releases на GitHub и скачать самую новую доступную версию<br>
После скачивания достаточно просто запустить .exe файл plant-care.exe<br>
Файл plant-care.exe можно запустить в тестовом режиме, нужно добавить всего лишь флаг --test<br>
Файл plant-care.exe также может запускаться в демо режиме, нужно добавить всего лишь флаг --demo<br>
